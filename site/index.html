文字相似度使用三字元片段 Jaccard 比較，0% 表示沒有共同片段，100% 表示片段集合相同。資料來源以政策 JSON 為主（HEART 官方 JSON、安可大舞台公開原始碼 JSON、臺北施政島公開原始碼 JSON）。它不比較視覺設計、3D 手感、語意或來源，也不能當作抄襲的認定依據。

Policy Change Archive / 政策變更檔案館

本專案是第三方技術觀察，與三個來源網站均無隸屬關係。所有時間為「本監測器抓到內容的時間」，不代表首次發布時間。原始快照可於各筆紀錄下載；監測程式與每日紀錄公開存放於 GitHub。任何 Git 紀錄都可能由有權限者重寫；關鍵證據建議交叉參照第三方封存。
